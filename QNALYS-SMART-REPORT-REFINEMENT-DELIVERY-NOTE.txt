2. TERMINOLOGY CHANGES (user-facing; AR + EN)
---------------------------------------------
Old                          New (AR)              New (EN)
Raw Score / الدرجة الخام  →  نسبة الجودة           Quality Rate
Weight / الوزن            →  النسبة المحددة        Defined Rate
Score (component)         →  النسبة المحققة        Achieved Rate
Contribution / الإسهام / المساهمة → النقاط المحتسبة Calculated Points
Weighted Total / الإجمالي الموزون → إجمالي النسبة المحتسبة Total Calculated Rate
Available weight / الوزن المتاح → النسبة المحددة المتاحة Defined rate available
Company KPI (partial)     →  النقاط المحتسبة + حالة التقييم: غير مكتمل
                             Calculated Points + Evaluation status: Incomplete
The words Weight/Weighted/Contribution no longer appear anywhere in the
report's user-facing UI (screen or print). Internal identifiers
(rawScore/weightedContribution/weight) are unchanged in code and engine.

3. KPI INCOMPLETE SEMANTICS (§4)
--------------------------------
Quality-only periods now read: "النقاط المحتسبة: 11.7 / 15" +
"حالة التقييم: غير مكتمل" — never "11.7% KPI". The KPI table's overall
row always carries its points context (X / Y). A final percentage is
shown ONLY when the engine verdict is complete ( AVAILABLE/FINALIZED).

-------------------------------

the REAL asset (dark wordmark on dark screens, print variant on light
theme and paper), balanced against the identity. Visual hierarchy:
Identity → Evaluation status → Executive summary → What changed →
Detail sections → Management attention (max 3) → Data quality → Analysis.
